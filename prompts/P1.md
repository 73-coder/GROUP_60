## Prompt 1: Create `prolog-dev` Skill File (`skills/prolog-dev/SKILL.md`)
Create a `SKILL.md` file for `prolog-dev` targeting SWI-Prolog 9.x. Start with a valid YAML frontmatter header (`name: prolog-dev` and `description`). Include clear instructions covering:
1. Language & Constraints: SWI-Prolog 9.x; files must contain only predicate definitions (no `initialization` directives, no `halt/0`, no `assert`, `retract`, `b_setval`, or `nb_setval`); only allowed libraries are `lists`, `apply`, `yall`, `aggregate`.

4. Mandatory Self-Review Checklist: Verify no singleton variables, exact atom/string types, deterministic vs. backtracking behavior, and adherence to allowed libraries before outputting code.
5. Known AI Failure Modes in Prolog: Using `=` instead of `is`/`=:=` for arithmetic, forgetting quotes around capitalized or symbolic atoms (like `'Alex'`, `'AI'`, `'c++'`), leaving stray choicepoints, and adding top-level queries or `initialization` directives.
